Flask + SQLite · 手工实现 · 14 项测试通过

1这是什么？

一句话：自己从零写的一个个人博客系统，不是套用现成博客程序。

技术栈：后端 Python / Flask，数据库 SQLite，前端原生 HTML / CSS / JavaScript（无任何前端框架）。代码全部可读，共 5 个 Python 源文件、 13 个页面模板、14 个自动化测试。

读者端（前台）功能

  • 首页时间轴刊列，按日期倒序展示文章
  • 文章详情：Markdown 渲染 + 代码高亮
  • 标签筛选、按年归档、RSS 订阅
  • 阅读计数、上一篇 / 下一篇导航
  • 深色 / 浅色模式一键切换

管理端（后台）功能

  • 登录鉴权（未登录无法进入后台）
  • 文章新建 / 编辑 / 删除
  • 草稿与发布状态管理（草稿前台不可见）
  • 标签、摘要随文章一起维护
  • 会话安全：HttpOnly + SameSite Cookie

2怎么运行？（三步）

不需要任何命令行知识，双击即可。

双击 01-【双击开始】.bat 脚本会自动检查 Python 和依赖，缺什么就装什么。
等待约 5 秒，浏览器自动打开 地址是 http://127.0.0.1:5000 ，看到「墨刊」首页即成功。
需要管理文章时，访问 /admin 登录后台 默认账号：admin / admin123（前台无需登录）。
注意：运行期间的黑色窗口不能关，关闭即停止服务。 想停止时在窗口里按 Ctrl + C。

4如何验证质量？（运行测试）

进入 02-项目源码 文件夹打开命令行（地址栏输入 cmd 回车），执行：

python -m unittest discover -s tests -t . -v
预期结果：结尾显示 Ran 14 tests 和 OK， 14 项全部 passed。测试使用独立的临时数据库，不会影响演示数据。

5常见问题

Q：双击后提示「没有检测到 Python 环境」？ 先到 python.org/downloads 安装 Python 3.9+，安装时务必勾选 “Add Python to PATH”，装完重新双击 01。
Q：依赖安装很慢或失败？ 在 02-项目源码 目录内手动执行：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple ，完成后重新双击 01。
Q：浏览器打不开页面？ 先看是不是已经有黑框窗口在运行（避免重复启动）；或等 3 秒按 F5 刷新。 仍不行则关闭所有黑框后重新双击 01。
Q：想修改管理员默认密码？ 删除 instance 文件夹后，设置环境变量 BLOG_ADMIN_PASSWORD 再启动， 首次建库时生效。课程演示环境保持默认即可。
