About this journal

「墨刊」是一个用 Flask 手工搭建的个人博客——从数据模型、路由、 模板到样式，每一行都是自己写的，没有套用任何博客系统。

技术栈

  • 后端：Flask（Blueprint 分层，前台 / 后台隔离）
  • 存储：SQLite，SQL 直写，无 ORM
  • 渲染：Python-Markdown + Pygments 代码高亮
  • 前端：原生 HTML / CSS / 少量 JavaScript，无构建步骤

功能

  • Markdown 写作、标签体系、草稿与发布
  • 管理后台（登录鉴权、文章增删改查）
  • 阅读计数、上下篇导航、按年归档、RSS 订阅
  • 深浅色模式切换，遵循 prefers-reduced-motion

联系

源码托管在 GitHub， 欢迎通过 Issue 交流。
